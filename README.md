Tugas Pertemuan 4, Mata kuliah pemrograman web

Kalkulator Patungan
Aplikasi berbasis web untuk menghitung pembagian tagihan secara praktis. Proyek ini dikembangkan untuk memenuhi tugas mata kuliah Pemrograman Web.

Gambaran Singkat
Program ini mempermudah pengguna saat membagi tagihan makan bersama teman. Logika perhitungannya sudah menyertakan pembulatan ke atas, sehingga uang yang terkumpul dijamin tidak kurang saat dibayarkan ke kasir.

Fitur Utama:
* Menghitung tagihan dasar beserta persentase tip secara otomatis.
* Pembulatan hasil bagi menggunakan fungsi `Math.ceil`.
* Mendukung eksekusi cepat cukup dengan menekan tombol **Enter**.
* Antarmuka (UI) yang rapi, ringkas.

Dirancang Menggunakan:
Proyek ini dibangun murni menggunakan standar web dasar:
* HTML5(Kerangka halaman)
* CSS3 (Penataan gaya dan tata letak)
* JavaScript (Logika perhitungan matematika)

Cara Menjalankan Program
1. Unduh kode dari repositori ini ke komputer.
2. Buka berkas `index.html` langsung melalui browser pilihan Anda.
